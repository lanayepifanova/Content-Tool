# Ratings Log

How to train the agent: open the latest brief, put `+` or `-` on each idea's
`rate:` line. Add a few words when the reason isn't obvious — those words are
worth more than the symbol.

```
`rate: -` too much like the Nvidia one from Tuesday
`rate: +` the absurdity-with-a-lesson thing, more of this
```

Then run `/basis-point-learn`. It reads every rated brief, distills the pattern,
and rewrites the LEARNED section of `agent/taste.md`. Ratings stay here as the
permanent record so the rubric can always be rebuilt from scratch.

Rate ruthlessly for the first week or two — a `-` on a merely-okay idea teaches
far more than a `+` on an obvious winner.
